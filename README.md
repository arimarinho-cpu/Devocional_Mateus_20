# Mateus 20.1–34: A Grande Inversão do Reino

Estudos Expositivos · Análise textual e exegética · Arisvaldo Marinho Cunha

Página estática com fundo musical (*Quiet Hope*), pronta para GitHub Pages.

## Estrutura

```
index.html
audio/quiet-hope.mp3
```

## Publicação no GitHub Pages

1. Envie `index.html` e a pasta `audio/` para a raiz do repositório (mantendo a pasta).
2. Em **Settings › Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. Aguarde a publicação e acesse o endereço indicado.

Observação: os navegadores bloqueiam a reprodução automática de áudio; por isso a música começa quando o leitor clica em "Iniciar com fundo musical".
